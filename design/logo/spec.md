## 1. 母题与推导链

```
参考视觉（旧版 app_icon.png：青蓝渐变圆角方 + 白色齿轮 + 圆内负空间）
  ├─ 空间事实 F1：对角蓝渐变容器（左上浅→右下深）      → 评分 High → 保留为图标壳与渐变方向
  ├─ 空间事实 F2：白色主体 + 蓝色负空间字腔的图底关系   → 评分 High → 转译为 A 的三角字腔
  └─ 品牌决策（用户确认）：抽象字母 A（AutoWork 首字母） → 双斜笔画 + 横杠，微喇叭腿求稳
```

标记构成 = 3 个图元：左斜笔画、右斜笔画、横杠（横杠两端嵌入笔画，形成闭合 A）。
总图元数 3 ≤ 6，通过 pre-flight。

## 2. 几何规范（0–100 设计坐标）

| 参数 | 值 | 说明 |
|---|---|---|
| 容器圆角 | 22.5% 边长 | Fluent 应用图标壳比例 |
| 标记顶点 y | 21 | 视觉居中偏上（抵消底部留白） |
| 标记底边 y | 79 | footprint 56×58，约占 56% 宽 |
| 笔画顶宽 / 底宽 | 11 / 16.5 | 微喇叭，16px 下笔画仍 ≥ 1.7px |
| 字腔 | 横杠上方蓝色三角 | 图底反转，继承旧图标"圆内留白"基因 |

## 3. 色彩规范

| 角色 | HEX | RGB | 用途 |
|---|---|---|---|
| 渐变亮端 | #60BCF0 | 96,188,240 | 容器左上（Fluent 蓝 #50B6E8 提亮） |
| 渐变暗端 | #0060B0 | 0,96,176 | 容器右下（Fluent 蓝 #0078D4 压深） |
| 标记色 | #FFFFFF | 255,255,255 | 字母 A |
| 层影 | #042A4F @55% | 4,42,79 | 标记柔和投影（Fluent 层次） |
| 玻璃高光 | #FFFFFF @≤10% | — | 容器上缘 30% 高度二次衰减带 |

对比度：白标记 vs 渐变暗端 ≈ 4.4:1，vs 中轴 #0D78C4 ≈ 4.0:1（大图形标记，通过）。

## 5. 使用规则

- 最小使用尺寸 16px（ICO 已含专用位图，无需再简化）。
- 深色/浅色桌面背景均直接可用（自带彩色容器）；单色场景可提取白色 A 置于任意品牌底。
- 禁止：拉伸变形、改变渐变方向、给 A 添加描边或立体效果。
- 替换应用图标：将 `autowork_logo.ico` 覆盖项目根目录 `app_icon.ico`（PyInstaller spec 引用该路径），并同步 `app_icon.png`。
