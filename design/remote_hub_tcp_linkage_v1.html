TCP 页签：行内「直连」= 对 frps serverAddr:remotePort 发起 SSH/SFTP （等价 TCP 直连模式，连接成功可选「存服务器」沉淀到保存列表）；http/https 页签提供复制/打开。
联动矩阵（按代理类型分派动作）： xtcp → 匹配注册表三态 + SSH/SFTP/注册/重连；tcp/udp → serverAddr:remotePort 直连 + 存服务器； stcp/sudp → 提示「需添加对应 visitor（三期扩展 stcp visitor 后自动可连）」； http/https/tcpmux → 复制域名 / 浏览器打开。
跨视图跳转：行内「质量」按钮 → 切「连接质量」视图并按 snk 过滤；代理行右键菜单同操作集。
数据纪律：全部动作复用既有单例（get_session_manager / TCPWorker / 保存列表）， frps 代理视图仍零额外请求（数据来自周期感知缓存）。
